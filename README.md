## The line

> My smartwatch congratulated me on standing up, which is the saddest standing ovation of my life.

96 characters, one sentence. The setup is an everyday truth — a fitness watch cheering a trivial act — and the punchline lands at the very end, a standing ovation for simply standing up.

## How it works

`main.ts` (Node, no dependencies) writes the line to `(OUTPUT_DIR ?? "/output") + "/entry.txt"`:

```sh
node main.ts
```
